# House style: review and re-theme plan

Status: **approved by Todd 2026-10-10**, with all three decisions as recommended. The rules are in `CLAUDE.md` under "Look and feel". The reference is Offcuts.

## What the review found

None of Crosscuts follows the house style yet. All of it was built on an earlier purple theme.

| Area | Now | House style |
|---|---|---|
| Page background | 6 different values (`#0a0607`, `#12131d`, `#15161c`, `#161826`, `#1b1d27`, `#1b1d2b`) | ink `#101019` everywhere |
| Accent | lavender `#9184d9` on every page | teal `#17C8A0`, the only working accent |
| Status colours | 3 greens, 5 reds, 4 ambers | go `#22C55E`, red `#EF4444` (overdue or destructive only), orange `#F97316` (attend to this) |
| Typeface | Inter, at 4 weights | Arial or Helvetica, bold and regular only |
| Buttons | mostly filled purple | outlined uppercase text |
| Badges | rounded pills | 16% fill plus a border, uppercase |
| Shadows | about 14, on menus, dialogs, cards and the login card | none |
| Icons | Phosphor: 8 in the menu bar, 3 on photo search, 11 on the board | none |
| Spectrum rule | absent | thin rule at the top and bottom of every page |
| Brand | the word "Crosscuts" with a purple square | text lockup **TH CABINETS**, like Offcuts |

Per page (details in the audit, file and line references available):
- **Menu bar (shell):** all of the above; it appears on every page except login, setup and photo search. (The board and Workers gained it on 2026-10-13, Todd: one consistent top header; the board's week buttons sit in a strip under it.)
- **Login and setup:** purple filled button and a card shadow.
- **Dashboard, Accounts, Design, Scheduling:** tiles with 12px corners, purple links, rounded "Planned" pills.
- **Photo admin:** closest to the house style (outlined buttons), but purple, pink "delete" and rounded tag pills.
- **Users:** filled buttons; its own green, amber and red; pill badges.
- **Audit:** filled button; amber highlights drawn with a shadow.
- **Jobs and job:** filled buttons; nine stage colours, none from the house palette.
- **Photo search:** shadows, hover lift, three icons; the logo image has a black box behind it, which shows once the page goes ink.
- **"No access" page** (generated by the server): hard-coded purple.
- **The board (schedule, workers, the JPG export):** purple everywhere, Inter, 11 icon buttons, shadows on the popover and dialog. It is protected by `CLAUDE.md` non-negotiable 7 ("the board files are not redesigned"), so it needs your decision.

## The plan

One milestone, **M1.2 House style**, released as **one** version (0.1.4). It also carries the GitHub Actions upgrade that is already committed, so the whole thing is one push and one CI run.

**Stage 1. Foundations**
- Replace `tokens.css` with the house tokens: ink, surface, raised, hairline, the text greys, teal, orange, go, red, the spectrum, and Arial. The old token names stay as aliases of the new values, so nothing breaks while pages move over.
- Add a shared `components.css` holding the house components, built once and copied from Offcuts:
  - outlined uppercase button
  - badge, pill and section bar
  - callout
  - label/value table
  - input and focus ring
- These replace 8 near-identical button, 7 input and 6 card definitions.
- Re-theme the menu bar:
  - TH CABINETS lockup on the left and the page name on the right
  - uppercase letterspaced links with a teal underline for the current page
  - no shadows
  - text labels instead of icons
  - the spectrum rule at the top of every page and the bottom of the page
- Re-theme the server's "No access" page.

**Stage 2. Pages:** login, setup, dashboard and the three placeholder pages, photo admin, users, audit, jobs and job, photo search.
- **Job stage colours** become:
  - neutral grey: lead, quoted
  - teal: won, design and ordering, on the board
  - orange: ready to cut (the "attend to this" stage)
  - green: complete, invoiced
  - muted: lost, archived
- The label always shows, so stages that share a colour are still told apart by name.
- **Photo search logo:** replaced by the TH CABINETS text lockup, unless you have a version of the logo with a transparent background.

**Stage 3. The board** (only if you include it, question 1 below)
- Colours, type, buttons and shadows move to the house style. The layout, the `.nav` and `alignPanels()` stay exactly as they are.
- Every visual change is mirrored in the JPG export, as non-negotiable 7 requires. The print version stays black on white paper.
- Flagged cells and the notes marker would both be orange. They stay distinct by shape: the flag is a left bar, the note is a dot.

**Stage 4. A guard so future builds keep the style**
- A new `ci/style-check.js`, run in CI before the image is built, fails the build if a page stylesheet or script:
  - uses a colour that isn't a house token
  - adds a shadow
  - loads Inter or Phosphor
  - uses a font weight other than regular or bold
- The check reads its allowed values from `tokens.css`, so the guide lives in one place. Whatever you exempt in the questions below (for example worker colours) is listed in the check by name.
- `CLAUDE.md` already states the rules for every future session and agent.

**Checks**
- Before and after screenshots of every page, taken locally in the built-in browser, for you to approve before anything is pushed.
- CI smoke tests as usual.
- After the update, you look over the pages on the device. If the board is included, that includes the TV and a JPG export.

## Decisions (Todd, 2026-10-10)

1. **Board: re-themed** (colours, type, buttons, shadows). Layout, `.nav`, `--nav-h` and `alignPanels()` stay as they are, everything is mirrored in `exportJpg()`, and print stays on white paper. `CLAUDE.md` non-negotiable 7 is reworded to match.
2. **Worker colours kept**, as a named exception.
3. **Icons: text on the menu bar and pages; the board keeps its icon buttons**, as the one other named exception.
